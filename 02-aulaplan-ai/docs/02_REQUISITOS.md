# 02 — Requisitos del equipo

## Versiones estándar del curso

```text
Git reciente
Node.js 24 LTS
npm
Python 3.11
Java 21
Firebase CLI
Netlify CLI
```

## Verificación macOS/Linux

```bash
git --version
node --version
npm --version
python3.11 --version
java --version
firebase --version
netlify --version
```

## Verificación Windows PowerShell

```powershell
git --version
node --version
npm --version
py -3.11 --version
java --version
firebase --version
netlify --version
```

## Importante sobre Python

Si tu sistema tiene Python 3.13, no lo desinstales. AulaPlan utiliza un `.venv` creado explícitamente con Python 3.11.
